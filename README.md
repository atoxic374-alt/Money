# مشروع إدارة بوتات ديسكورد الموسيقية

هذا المشروع عبارة عن نظام متكامل لإدارة ونشر بوتات ديسكورد الموسيقية، مصمم لتقديم خدمة اشتراكات للمستخدمين. يتكون النظام من بوت تحكم رئيسي يقوم بإدارة عدة بوتات موسيقية فرعية، وتتبع اشتراكات المستخدمين، وتخصيص البوتات لهم.

## الميزات الرئيسية

*   **إدارة البوتات الموسيقية:** يسمح النظام بنشر وإدارة عدة بوتات ديسكورد مخصصة لتشغيل الموسيقى.
*   **نظام الاشتراكات:** يدعم النظام الاشتراكات للمستخدمين، حيث يمكن تخصيص بوتات موسيقية لهم لفترة محددة.
*   **تتبع انتهاء الصلاحية:** يقوم البوت الرئيسي بتتبع تواريخ انتهاء صلاحية الاشتراكات وإرسال إشعارات للمستخدمين.
*   **أوامر التحكم:** يوفر البوت مجموعة من الأوامر للتحكم في تشغيل الموسيقى، وإدارة البوتات، وعرض تفاصيل الاشتراكات.
*   **تكامل Lavalink:** يستخدم المشروع مكتبة Poru للاتصال بخوادم Lavalink، مما يتيح تشغيل الموسيقى بكفاءة.

## هيكلية المشروع

يتكون المشروع من عدة ملفات ومجلدات رئيسية:

*   `index.js`: نقطة الدخول الرئيسية للبوت التحكم. يقوم بتحميل الأوامر ومعالجات الأحداث.
*   `manager.js`: مسؤول عن مراقبة ملف `settings/tokens.json` وتشغيل مثيلات بوتات الموسيقى الفرعية لكل توكن نشط.
*   `music.js`: يحتوي على المنطق الأساسي لتشغيل الموسيقى باستخدام Poru (عميل Lavalink) ويتعامل مع أحداث ديسكورد المتعلقة بالموسيقى.
*   `commands/`: يحتوي على مجلدات فرعية للأوامر المختلفة (مثل `Auto-Purchase`, `Control`, `Subscriptions`).
*   `handler/`: يحتوي على معالجات الأحداث الخاصة بالبوت.
*   `settings/`: يحتوي على ملفات الإعدادات والتكوين الرئيسية للمشروع.
    *   `config.json`: إعدادات البوت الرئيسية مثل التوكن، البادئة، معرف قناة السجل، الألوان، ومعرفات المالكين.
    *   `host.json`: إعدادات خادم Lavalink (يجب تكوينه يدويًا).
    *   `bots.json`: قائمة بتوكنات البوتات الموسيقية المتاحة للاشتراكات.
    *   `tokens.json`: قائمة بتوكنات البوتات الموسيقية المخصصة حاليًا للمستخدمين.
    *   `time.json`: يسجل تفاصيل الاشتراكات النشطة وتواريخ انتهائها.


## Lavalink الصوتي الرسمي

تمت إعادة هيكلة تشغيل الصوت ليعتمد على Lavalink الرسمي بدل خادم الصوت JS المخصص. هذا هو الأسلوب الأكثر استخداماً في بوتات الموسيقى لأنه يفصل تشغيل الصوت في خدمة Java مستقرة وقليلة الاستهلاك، ويدعم تحديثات Discord الصوتية الحديثة مثل DAVE/E2EE التي تمنع خطأ Voice Gateway `4017`.

### تشغيل Lavalink

```bash
npm run lavalink
```

المشغل سيحمّل `Lavalink.jar` الرسمي داخل `lavalink-server/data/` أول مرة، ثم يعيد استخدامه بعد ذلك. إعداد اتصال البوت موجود في `settings/host.json` ويشير إلى `127.0.0.1:2333`.

### تشغيل البوت

شغّل Lavalink أولاً ثم البوت:

```bash
npm run lavalink
npm start
```

أو شغّل الاثنين معاً من أمر واحد:

```bash
npm run start:all
```

على Replit تأكد أن `replit.nix` يحتوي Java 21 و FFmpeg. يمكن تقليل الذاكرة عبر المتغير:

```bash
LAVALINK_MAX_RAM=256m npm run lavalink
```

## كيفية التشغيل

لتشغيل هذا المشروع، اتبع الخطوات التالية:

### المتطلبات الأساسية

*   **Node.js:** تأكد من تثبيت Node.js (الإصدار 16 أو أحدث موصى به).
*   **npm أو Yarn:** مدير حزم Node.js.
*   **خادم Lavalink:** يجب أن يكون لديك خادم Lavalink قيد التشغيل. يمكنك العثور على إرشادات حول كيفية إعداد Lavalink في [وثائق Lavalink الرسمية](https://lavalink.dev/).
*   **توكنات بوتات ديسكورد:** ستحتاج إلى توكنات لبوت التحكم الرئيسي وتوكنات إضافية للبوتات الموسيقية التي سيتم تخصيصها للمستخدمين.

### خطوات الإعداد والتشغيل

1.  **استنساخ المستودع:**
    ```bash
    git clone https://github.com/atoxic374-alt/Money.git
    cd Money
    ```

2.  **تثبيت التبعيات:**
    ```bash
    npm install
    # أو
    yarn install
    ```

3.  **تكوين ملفات الإعدادات:**

    *   **`settings/config.json`:**
        *   `Token`: توكن بوت ديسكورد الرئيسي الخاص بك.
        *   `prefix`: البادئة التي سيستخدمها البوت للأوامر (مثال: `!`).
        *   `logChannelId`: معرف قناة ديسكورد حيث سيتم تسجيل الإشعارات.
        *   `owners`: مصفوفة تحتوي على معرفات المستخدمين (IDs) للمالكين.
        *   `Colors`: رمز لون سداسي عشري (مثال: `#7d8b7f`).
        *   `Email`, `client_secret`, `client_id`, `TwitchUrl`: قد تكون هذه الإعدادات متعلقة بتكاملات إضافية أو ميزات محددة. املأها حسب الحاجة أو اتركها فارغة إذا لم تكن تستخدمها.

    *   **`settings/host.json`:**
        يجب تكوين هذا الملف بتفاصيل خادم Lavalink الخاص بك. مثال:
        ```json
        [
          {
            "host": "your_lavalink_host",
            "port": 2333,
            "password": "your_lavalink_password",
            "secure": false
          }
        ]
        ```
        استبدل `your_lavalink_host` و `your_lavalink_password` بالقيم الصحيحة لخادم Lavalink الخاص بك.

    *   **`settings/bots.json`:**
        املأ هذا الملف بتوكنات بوتات ديسكورد الإضافية التي ستكون متاحة للاشتراكات. كل توكن يجب أن يكون كائنًا منفصلاً:
        ```json
        [
          {
            "token": "YOUR_BOT_TOKEN_1"
          },
          {
            "token": "YOUR_BOT_TOKEN_2"
          }
        ]
        ```

4.  **تشغيل البوت:**
    ```bash
    node index.js
    ```
    سيقوم هذا الأمر بتشغيل بوت التحكم الرئيسي، والذي بدوره سيبدأ في إدارة بوتات الموسيقى الفرعية بناءً على الاشتراكات في `settings/tokens.json`.

## الأوامر (أمثلة)

يمكن للمستخدمين التفاعل مع البوت الرئيسي والبوتات الموسيقية باستخدام الأوامر. على سبيل المثال، قد تتضمن الأوامر:

*   `!play [اسم الأغنية/رابط]`: لتشغيل أغنية.
*   `!queue`: لعرض قائمة الانتظار.
*   `!mysub`: لعرض تفاصيل اشتراك المستخدم.
*   `!madd-sub`: (للمالكين) لإضافة اشتراك جديد.

يرجى الرجوع إلى ملفات الأوامر في مجلد `commands/` للحصول على قائمة كاملة بالأوامر المتاحة ووظائفها.

## ملاحظات هامة

*   **الأمان:** تأكد من حماية توكنات البوتات الخاصة بك ولا تشاركها علنًا.
*   **Lavalink:** بدون خادم Lavalink يعمل بشكل صحيح، لن تتمكن بوتات الموسيقى من تشغيل أي صوت.
*   **إدارة الاشتراكات:** يتم إدارة الاشتراكات وتخصيص التوكنات تلقائيًا بواسطة البوت الرئيسي بناءً على الملفات في مجلد `settings/`.
